# Структура проекта СНЭЭ

## Основные файлы программы

### 🚀 Запуск и компиляция
- **`main.py`** - Точка входа в приложение, создание QApplication
- **`run.bat`** - Скрипт автоматического запуска (Windows)
- **`build.bat`** - Скрипт компиляции в EXE файл (PyInstaller)

### 🖥️ Графический интерфейс
- **`main_window.py`** - Главное окно приложения (PyQt6)
  - Таблицы редактирования данных
  - Панель параметров СНЭЭ
  - Интеграция с веб-представлением для графиков
  - Обработчики событий и управление состоянием

### 🧮 Ядро расчетов
- **`energy_storage_calculator.py`** - Алгоритм расчета диспетчерского графика
  - Класс `EnergyStorageCalculator`
  - Метод water-filling для оптимального распределения энергии
  - Расчет сводной статистики
  - Валидация входных данных

### 📊 Визуализация
- **`visualization.py`** - Генерация интерактивных графиков
  - Класс `ChartGenerator`
  - Создание графиков с Plotly
  - Двухпанельное отображение (баланс + SOC)
  - Экспорт в HTML

### 💾 Управление данными
- **`data_manager.py`** - Импорт/экспорт данных
  - Класс `DataManager`
  - Импорт профилей из Excel
  - Экспорт результатов в Excel (два листа)
  - Данные по умолчанию

## Конфигурация и зависимости

### ⚙️ Настройки
- **`env.example`** - Пример файла конфигурации
  - Параметры СНЭЭ по умолчанию
  - Размеры окна приложения
  - Используется для создания `.env`
- **`.env`** - Реальный файл конфигурации (НЕ включен в git/cursor)

### 📦 Зависимости
- **`requirements.txt`** - Список Python пакетов
  ```
  numpy>=1.24.0          # Численные расчеты
  pandas>=2.0.0          # Работа с данными
  openpyxl>=3.1.0        # Excel файлы
  plotly>=5.18.0         # Интерактивные графики
  PyQt6>=6.6.0           # GUI фреймворк
  python-dotenv>=1.0.0   # Загрузка .env
  pyinstaller>=6.0.0     # Компиляция в EXE
  ```

### 🚫 Игнорирование
- **`.gitignore`** - Файлы для исключения из Git
  - venv/, __pycache__, build/, dist/
  - .env, *.xlsx, временные файлы
- **`.cursorignore`** - Файлы для исключения из Cursor AI
  - .env, venv/, build/, dist/
