# Технические примечания

## Алгоритм расчета (Water-Filling)

### Суть метода

Алгоритм **water-filling** (заполнение водой) используется для оптимального распределения ограниченного ресурса (энергии в батарее) по времени суток.

Аналогия: представьте, что у вас есть 24 сосуда разной высоты (баланс мощности), и вы наливаете в них воду (энергию) до определенного уровня - это и есть water-filling.

### Этапы расчета

1. **Определение лимитов**
   - Почасовые лимиты заряда (зависят от избытка мощности)
   - Почасовые лимиты разряда (зависят от дефицита мощности)
   - Учет номинальной мощности инвертора
   - Учет КПД полуцикла (√КПД)

2. **Расчет используемой энергии**
   ```
   UsedCapacity = min(
       Суммарный возможный заряд,
       Суммарный возможный разряд,
       Номинальная емкость батареи
   )
   ```

3. **Определение уровня заряда**
   - Методом water-filling находится оптимальный уровень
   - Заряд происходит в часы, когда баланс выше этого уровня
   - Энергия "срезается" с профиля и запасается в батарее

4. **Определение уровня разряда**
   - Аналогично находится оптимальный уровень разряда
   - Разряд происходит в часы, когда баланс ниже этого уровня
   - Энергия "добавляется" к профилю из батареи

5. **Формирование графика**
   - Учитываются потери при заряде и разряде
   - Гарантируется баланс: суммарный заряд = суммарный разряд

### Математические особенности

**КПД полуцикла:**
```
η_half = √η_cycle

Пример: при КПД цикла 0.95
η_half = √0.95 ≈ 0.9747
```

**Энергия на шинах:**
- При заряде: E_шины = E_батарея / η_half (берем из сети больше)
- При разряде: E_шины = E_батарея × η_half (отдаем в сеть меньше)

**Сортировка событий:**
Используется Comb Sort для эффективной сортировки событий входа/выхода из интервалов при water-filling.

## Визуализация (Plotly)

### Почему Plotly?

1. **Интерактивность**
   - Масштабирование графика
   - Панорамирование
   - Всплывающие подсказки
   - Включение/выключение серий

2. **Качество**
   - Векторная графика
   - Профессиональный внешний вид
   - Экспорт в PNG/SVG прямо из графика

3. **Современность**
   - Используется в Jupyter, Dash
   - Активная разработка
   - Большое сообщество

### Особенности реализации

**Два подграфика:**
1. Баланс мощности + график СНЭЭ
2. Состояние заряда батареи (SOC)

**Цветовая схема:**
- Красный - дефицит/заряд батареи
- Зеленый - разряд СНЭЭ (помощь сети)
- Синий - заряд СНЭЭ (накопление)
- Серый - результирующий баланс

**Интеграция с PyQt6:**
```python
QWebEngineView  # Встроенный браузер для отображения Plotly
```


## Известные ограничения

1. **24 часа фиксировано**
   - Алгоритм рассчитан на суточный цикл
   - Для других периодов требует доработки

2. **Круглосуточный баланс = 0**
   - Батарея начинает и заканчивает разряженной
   - Для изменения требуется модификация алгоритма

3. **Один СНЭЭ**
   - Не поддерживается несколько накопителей
   - Не учитывается географическое распределение

4. **Детерминированный расчет**
   - Нет учета неопределенности прогноза
   - Нет стохастической оптимизации
