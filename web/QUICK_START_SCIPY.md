# 🚀 Быстрый старт - Исправленная версия с scipy

## ✅ Что было исправлено?

Проблема с некорректными расчетами оценочных параметров **ПОЛНОСТЬЮ РЕШЕНА!**

**До исправления:**
```
❌ rated_power_in_mw: 2.17e+127 МВт  (абсурдно большое число)
❌ termination_code: -2               (ошибка оптимизации)
```

**После исправления:**
```
✅ rated_power_in_mw: 50.22 МВт      (разумное значение)
✅ rated_power_out_mw: 49.79 МВт     (разумное значение)
✅ capacity_mwh: 229.92 МВтч         (разумное значение)
✅ termination_code: 4                (успех!)
```

## 📋 Что было изменено?

1. **Отказ от alglib-cpython** → Использование **scipy.optimize**
   - Причина: alglib-cpython давал некорректные результаты
   - Решение: scipy.optimize с методом trust-constr

2. **Исправление MAX_REAL_NUMBER** в `ppw_calculator.py`
   - Было: `1e+300` (вызывало переполнение)
   - Стало: `np.inf` (корректно обрабатывается)

3. **Добавлена зависимость scipy**
   - Уже установлена: `scipy>=1.11.0`

| Код | Описание | Статус |

## 🔧 Устранение проблем

### Проблема: Backend не запускается

**Решение:**
```bash
cd web/backend
pip install -r requirements.txt
python main.py
```

### Проблема: Ошибка импорта scipy

**Решение:**
```bash
pip install scipy>=1.11.0
```

### Проблема: Оценочные параметры все еще огромные

**Причина:** Backend не перезапустился после изменений

**Решение:**
```bash
# Windows:
taskkill /F /IM python.exe

# Linux/Mac:
pkill python

# Запустите снова:
cd web/backend
python main.py
```

### Проблема: Код завершения -2 или -3

**Причина:** Оптимизатор не может найти допустимое решение

**Возможные причины:**
1. Слишком жесткие ограничения (проверьте входные параметры)
2. Несовместимые ограничения (проверьте профиль баланса)
3. Начальное приближение далеко от решения

**Решение:** Проверьте входные данные на разумность
