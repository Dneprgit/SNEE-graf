# Тестирование СНЭЭ Graf Web

Руководство по тестированию веб-приложения.

## Тестирование Backend API

### 1. Ручное тестирование через Swagger UI

1. Запустите backend:
```bash
cd backend
python -m uvicorn main:app --reload
```

2. Откройте в браузере: http://localhost:8001/docs

3. Протестируйте каждый endpoint:

#### Health Check
- Endpoint: `GET /api/v1/health`
- Ожидаемый результат: `{"status": "healthy"}`

#### Default Profile
- Endpoint: `GET /api/v1/default-profile`
- Ожидаемый результат: массив из 24 чисел

#### Calculate Schedule
- Endpoint: `POST /api/v1/calculate`
- Тестовые данные:
```json
{
  "load_profile": [
    1320, 1515, 1623, 1769, 1854, 1791, 1409, 860, 227, -261,
    -618, -779, -845, -927, -927, -927, -862, -799, -669, -535,
    -638, -370, 59, 963
  ],
  "rated_power_mw": 500,
  "rated_capacity_mwh": 2000,
  "efficiency": 0.95
}
```

### 2. Тестирование через curl

```bash
# Health check
curl http://localhost:8001/api/v1/health

# Получить профиль по умолчанию
curl http://localhost:8001/api/v1/default-profile

# Расчет графика
curl -X POST http://localhost:8001/api/v1/calculate \
  -H "Content-Type: application/json" \
  -d '{
    "load_profile": [1320, 1515, 1623, 1769, 1854, 1791, 1409, 860, 227, -261, -618, -779, -845, -927, -927, -927, -862, -799, -669, -535, -638, -370, 59, 963],
    "rated_power_mw": 500,
    "rated_capacity_mwh": 2000,
    "efficiency": 0.95
  }'

# Валидация профиля
curl -X POST http://localhost:8001/api/v1/validate-profile \
  -H "Content-Type: application/json" \
  -d '[1320, 1515, 1623, 1769, 1854, 1791, 1409, 860, 227, -261, -618, -779, -845, -927, -927, -927, -862, -799, -669, -535, -638, -370, 59, 963]'
```

### 3. Тестирование загрузки Excel

```bash
# Создайте тестовый Excel файл или используйте существующий
curl -X POST http://localhost:8001/api/v1/upload-excel \
  -F "file=@test_data.xlsx"
```

1. Запустите оба сервиса

4. Выполните расчет
5. **Проверьте**:

   - Нет CORS ошибок
   - Время ответа < 1 секунды

1. **Шаг 1**: Загрузите данные из Excel

**Ожидаемый результат**: Все шаги выполнены без ошибок

## Автоматизированное тестирование

### Backend Unit Tests (будущая разработка)

```python
# test_api.py
import pytest
from fastapi.testclient import TestClient
from main import app

client = TestClient(app)

def test_health_check():
    response = client.get("/api/v1/health")
    assert response.status_code == 200
    assert response.json()["status"] == "healthy"

def test_calculate():
    data = {
        "load_profile": [0] * 24,
        "rated_power_mw": 500,
        "rated_capacity_mwh": 2000,
        "efficiency": 0.95
    }
    response = client.post("/api/v1/calculate", json=data)
    assert response.status_code == 200
```

## Известные проблемы и ограничения

1. **Размер файла Excel**: Максимум 10 МБ (настраивается в nginx.conf)
2. **Браузеры**: IE 11 не поддерживается
3. **Мобильные**: Графики могут быть менее читаемы на маленьких экранах
4. **Производительность**: SVG анимация может тормозить на слабых устройствах
