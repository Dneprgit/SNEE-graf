# Алгоритм квадратичной оптимизации (QP) для СНЭЭ

## Описание

Реализован алгоритм квадратичной оптимизации для определения оптимальных параметров системы накопления электрической энергии (СНЭЭ). Алгоритм перенесён из VB кода (функция `GetEESSOptimizedParameters` в файле `Module1.bas`) и адаптирован для Python с использованием библиотеки scipy.

## Отличия от алгоритма water-filling

### Первый вариант (water-filling):
- Определяет только два параметра: мощность инвертора и емкость батареи
- Использует бинарный поиск для минимизации дефицита
- Предполагает симметричную систему (одинаковая мощность заряда и разряда)

### Второй вариант (QP):
- Определяет **четыре** основных параметра:
  1. **Номинальная входная мощность** (Nin) - мощность заряда
  2. **Номинальная выходная мощность** (Nout) - мощность разряда
  3. **Емкость батареи** (C)
  4. **Дефицит активной мощности** (Dmax)
- Использует метод квадратичной оптимизации с линейными ограничениями
- Позволяет асимметричную систему (разные мощности заряда и разряда)
- Оптимизирует все параметры одновременно

## Математическая постановка задачи

### Целевая функция (минимизировать):
```
F(x) = 0.5 * x' * A * x + b' * x
```

Где:
- `A` - диагональная матрица с малым усилением (0.00000001)
- `b` - вектор весов:
  - `b[1..72] = 0` (для переменных dL, CC, CD)
  - `b[73] = 1.0` (вес для дефицита мощности)
  - `b[74] = 0.02` (вес для входной мощности)
  - `b[75] = 0.02` (вес для выходной мощности)
  - `b[76] = 0.0008` (вес для емкости)

### Переменные (n = 76):
1. `dL[1..24]` - уровень энергии в батарее по часам
2. `CC[1..24]` - почасовой заряд
3. `CD[1..24]` - почасовой разряд
4. `Dmax` - дефицит активной мощности
5. `Nin` - номинальная входная мощность
6. `Nout` - номинальная выходная мощность
7. `C` - емкость батареи

### Ограничения (k = 120):
1. **rL** (баланс энергии): `dL[i] - dL[i-1] - CC[i] + CD[i] = 0`
2. **rD** (баланс мощности): `-CC[i]/η + CD[i] + Dmax >= Load[i]`
3. **rC** (емкость): `-dL[i] + C >= 0`
4. **rNi** (входная мощность): `-CC[i]/η + Nin >= 0`
5. **rNo** (выходная мощность): `-CD[i] + Nout >= 0`

Все переменные неотрицательные: `x[i] >= 0`

## Выходные параметры

### Основные:
- `optimal_power_in_mw` - номинальная входная мощность (МВт)
- `optimal_power_out_mw` - номинальная выходная мощность (МВт)
- `optimal_capacity_mwh` - емкость батареи (МВтч)
- `deficit_mw` - дефицит активной мощности (МВт)

### Дополнительные (рассчитываются на frontend):
- `discharge_time` - фактическое время разряда (ч) = C / Nout
- `charge_energy` - энергия, затраченная на заряд (МВтч) = C / η
- `charge_time` - фактическое время заряда (ч) = (C / η) / Nin

## Зависимости

- `scipy>=1.10.0` - для квадратичной оптимизации
- `numpy>=1.24.0` - для работы с массивами

## Примечания

1. Алгоритм использует `scipy.optimize.minimize` с методом `'trust-constr'`
2. Начальное приближение: `x0[i] = lb[i] + 1.0`
3. Проверка баланса заряд-разряд: `Σ(CC[i] - CD[i]) < 0.001`
4. Максимальное количество итераций: 1000

## Сравнение с VB кодом

| Параметр | VB (ALGLIB) | Python (scipy) |
|----------|-------------|----------------|
| Библиотека | alglib (коммерческая) | scipy (открытая) |
| Солвер | BLEIC-QP | trust-constr |
| Точность | ~0.001 | ~0.001 |
| Скорость | Быстрее | Сравнимая |

Результаты должны быть близки к результатам из VB кода, но могут незначительно отличаться из-за разных алгоритмов оптимизации.
