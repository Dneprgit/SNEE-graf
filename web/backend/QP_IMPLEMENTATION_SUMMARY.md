### 2. Реализованные функции в `energy_storage_calculator.py`

#### 2.1. `calculate_optimal_parameters_qp()`
**Назначение:** Расчет оптимальных параметров СНЭЭ методом квадратичной оптимизации

**Портировано из:** VB функция `GetEESSOptimizedParameters()` (Module1.bas)

**Входные параметры:**
- `load_profile`: Суточный профиль баланса мощности (24 часа)
- `efficiency`: КПД цикла заряда-разряда (0-1)

**Возвращаемые значения:**
```python
{
    'nin': float,           # Номинальная активная входная мощность, МВт
    'nout': float,          # Номинальная активная выходная мощность, МВт
    'capacity': float,      # Энергия, фактически отдаваемая в рабочем диапазоне, МВтч
    'deficit': float,       # Дефицит мощности результирующий, МВт
    'eens_energy_available': List[float],  # Массив уровней накопленной энергии (24 часа)
    'eens_load': List[float]  # Массив нагрузки СНЭЭ (24 часа)
}
```

**Алгоритм:**
1. Построение задачи квадратичной оптимизации с 76 переменными:
   - dL[0:23] - уровень накопленной энергии
   - CC[24:47] - заряд в каждый час (внутренний)
   - CD[48:71] - разряд в каждый час (внутренний)
   - Dmax[72] - дефицит мощности результирующий
   - Nin[73] - оптимальная входная мощность
   - Nout[74] - оптимальная выходная мощность
   - C[75] - оптимальная емкость

2. Целевая функция: minimize F(x) = 0.5*x'*A*x + b'*x
   - A - почти нулевая матрица с диагональным усилением 0.00000001
   - b - вектор весов [0...0, 1, 0.02, 0.02, 0.0008]

3. Ограничения (120 линейных ограничений):
   - rL[0:23]: Балансовые (изменение уровня = разряд - заряд)
   - rD[0:23]: Покрытие дефицита нагрузки
   - rC[0:23]: Ограничение емкости батареи
   - rNi[0:23]: Ограничение входной мощности
   - rNo[0:23]: Ограничение выходной мощности

4. Решение методом `trust-constr` из scipy.optimize

#### 2.2. `calculate_dispatch_schedule_qp()`

- `nout`: Номинальная активная выходная мощность, МВт
- `capacity`: Энергия, фактически отдаваемая в рабочем диапазоне, МВтч
- `efficiency`: КПД цикла заряда-разряда (0-1)

**Возвращаемые значения:**
