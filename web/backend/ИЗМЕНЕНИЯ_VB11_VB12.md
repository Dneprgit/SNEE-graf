# Краткая сводка изменений VB11 → VB12

## Файл обновлен
`web/backend/energy_storage_calculator_.py`

## Основные изменения

### 1. Функция `_solve_qp_optimization` (оптимизация с заданными параметрами)

✅ **Добавлены параметризованные веса:**
- `dbl_dmax_weight = 1.0`
- `dbl_d_weight = dbl_dmax_weight / 25`
- `dbl_rmax_weight = dbl_d_weight / 25`

✅ **Изменены границы для дефицита:**
- Было: `ub[D[i]] = infinity`
- Стало: `ub[D[i]] = max(0, system_load[i])`

✅ **Улучшено начальное приближение:**
- Учитывает реальные границы переменных
- Более умная инициализация x0

### 2. Функция `calculate_optimal_parameters_qp` (поиск оптимальных параметров)

✅ **Увеличено количество переменных:**
- Было: 76 переменных (im*3 + 4)
- Стало: 100 переменных (im*4 + 4)
- Добавлены: D[] - почасовой дефицит (24 переменные)

✅ **Добавлены новые ограничения:**
- Было: 120 ограничений (5 типов)
- Стало: 144 ограничения (6 типов)
- Добавлено: rDmax - ограничение максимального дефицита

✅ **Изменена структура ограничения rD:**
- Было: использует Dmax (общий дефицит)
- Стало: использует D[i] (почасовой дефицит)

✅ **Улучшено начальное приближение:**
- Специальная логика расчета емкости
- Расчет мощности заряда-разряда
- Расчет дефицита и максимумов
- Значительно повышает сходимость!

✅ **Обновлены индексы результата:**
- Все индексы сдвинуты из-за добавления D[]
- Dmax: index 96 (было 72)
- Nin: index 97 (было 73)
- Nout: index 98 (было 74)
- Capacity: index 99 (было 75)

## Структура переменных (VB12)

```
x[0..23]   - L[]    - энергия в батарее (МВтч)
x[24..47]  - CC[]   - мощность заряда (МВт)
x[48..71]  - CD[]   - мощность разряда (МВт)
x[72..95]  - D[]    - дефицит по часам (МВт) ⭐ НОВОЕ
x[96]      - Dmax   - максимальный дефицит (МВт)
x[97]      - Nin    - входная мощность (МВт)
x[98]      - Nout   - выходная мощность (МВт)
x[99]      - C      - емкость батареи (МВтч)
```

## Типы ограничений (VB12)

1. **rL** - баланс энергии в батарее (24)
2. **rD** - баланс мощности (24)
3. **rC** - ограничение емкости (24)
4. **rNi** - ограничение входной мощности (24)
5. **rNo** - ограничение выходной мощности (24)
6. **rDmax** - ограничение максимального дефицита (24) ⭐ НОВОЕ

1. 🎯 **Более точная модель** - почасовой дефицит вместо общего

3. 📊 **Реалистичные границы** - учет фактической нагрузки
4. ⚙️ **Гибкие настройки** - параметризованные веса
5. ✅ **Консистентность** - дополнительные ограничения
