# Быстрый старт - Вариант PPW

## ✅ Что реализовано

### 1. График "Суточный баланс мощности энергосистемы" ✅
Теперь отображает **все три графика** на одном:
- **Исходный баланс** (синяя линия) - исходные данные баланса мощности
- **Нагрузка СНЭЭ** (столбики) - зеленые для разряда (+), красные для заряда (-)
- **Результирующий баланс** (фиолетовая линия) - баланс с учетом работы СНЭЭ

Используется `ComposedChart` из Recharts для объединения Line и Bar графиков.

### 2. BatteryInteractiveSection_ppw ✅
Полностью реализованная интерактивная секция с:
- **Текущими параметрами** (10 полей с цветовым кодированием)
- **Оценочными параметрами** (автоматический расчет через API)
- **Кнопкой "Установить оценочные параметры"** - применяет оценочные значения к текущим
- **SVG визуализацией** с прямоугольниками заряда/разряда
- **Пунктирными линиями** оценочных параметров на графике

## 📊 Как пользоваться

### Шаг 1: Переключение на PPW вариант
1. Откройте http://localhost:5173
2. В Hero секции нажмите на таб **"Вариант 2 (PPW)"**

### Шаг 2: Загрузка данных
1. Нажмите **"Загрузить профиль по умолчанию"**
2. Или загрузите свой Excel файл
3. Или вставьте 24 значения в первое поле (Ctrl+V)

**Дефолтные данные:**
```
27, 38, 84, 137.54, 21.33, -115.19, -166.18, -185.59, -130.30, -48.17,
37.55, 152, 103, 175, 99, 49, -47, 7, -130, -176, -117, -222, -205, -166
```

### Шаг 3: Настройка параметров СНЭЭ
По умолчанию установлены:
- Номинальная входная мощность: **95 МВт**
- Номинальная выходная мощность: **140 МВт**
- Номинальная энергоемкость: **400 МВтч**
- КПД: **95%**
- Коэффициент использования емкости: **90%**

Остальные параметры рассчитываются автоматически.

### Шаг 4: Расчет графика
1. Нажмите **"Рассчитать график"**
2. Дождитесь завершения расчета (~1-2 секунды)

### Шаг 5: Изучение результатов

#### Ключевые показатели (верхние карточки):
- Заряд (МВтч)
- Разряд (МВтч)
- Покрыто дефицита (МВтч)
- Использовано избытка (МВтч)

#### Основной график:
- **Синяя линия**: Исходный баланс мощности
- **Зеленые столбики**: Разряд СНЭЭ (выдача в сеть)
- **Красные столбики**: Заряд СНЭЭ (потребление из сети)
- **Фиолетовая линия**: Результирующий баланс с учетом СНЭЭ

#### График SOC:
- Показывает состояние заряда батареи в течение суток

## 🎯 Работа с оценочными параметрами

### Автоматический расчет
Оценочные параметры рассчитываются автоматически при:
- Загрузке профиля
- Изменении КПД

### Интерактивная секция параметров

**Текущие параметры** (слева):
- Показывает ваши настройки
- Выделены важные поля (входная/выходная мощность, энергия)

**Оценочные параметры** (справа):
- Рассчитаны алгоритмом квадратичной оптимизации
- **Красный цвет**: входная мощность и энергия заряда
- **Зеленый цвет**: выходная мощность и энергия разряда
- **Фиолетовый цвет**: время разряда/заряда
- **Желтый цвет**: КПД

**Кнопка "Установить оценочные параметры"**:
- Копирует оценочные значения в текущие параметры
- Автоматически пересчитывает график

### SVG визуализация
- **Зеленый прямоугольник**: Энергия разряда (текущая)
- **Красный прямоугольник**: Энергия заряда (текущая)
- **Пунктирные линии**: Оценочные параметры для сравнения

## 📐 Математическая модель

### Задача оптимизации
```
Минимизировать: F(x) = 0.5*x'*A*x + b'*x

При ограничениях:
  lb <= x <= ub
  cl <= C'*x <= cu
```

### Алгоритм
- **IPM** (Interior Point Method) из библиотеки alglib
- Точное решение задачи квадратичного программирования
- Автоматическая балансировка заряда/разряда

### Переменные
- **calculate_optimal_load**: 98 переменных, 96 ограничений
- **calculate_optimized_parameters**: 76 переменных, 120 ограничений

## 🔧 Технические детали

### API Endpoints

#### Расчет графика
```
POST /api/v1/ppw/calculate-load
{
  "system_load": [24 значения],
  "rated_power_in_mw": 95,
  "rated_power_out_mw": 140,
  "capacity_mwh": 360,
  "efficiency": 0.95
}
```

#### Расчет оптимальных параметров
```
POST /api/v1/ppw/calculate-optimal-parameters
{
  "system_load": [24 значения],
  "efficiency": 0.95
}
```

### Коды завершения оптимизации
- **2, 4**: ✅ Успешное завершение (оптимально)
- **1, 5, 7, 8**: ✅ Успешное завершение (приемлемо)
- **-2, -3, -4**: ❌ Ошибки оптимизации

## 🎨 Цветовая схема

- 🔴 **Красный**: Входная мощность, заряд, энергия заряда
- 🟢 **Зеленый**: Выходная мощность, разряд, энергия разряда
- 🟣 **Фиолетовый**: Время (разряд/заряд)
- 🟡 **Желтый**: КПД, энергоэффективность
- 🔵 **Синий**: Исходный баланс мощности

## 📊 Сравнение текущих и оценочных параметров

### Зачем нужны оценочные параметры?
Оценочные параметры показывают **минимально необходимые** значения мощности и емкости СНЭЭ для оптимальной работы с данным профилем баланса.

### Как сравнить?
1. Посмотрите на **оценочные параметры** в интерактивной секции
2. Сравните с **текущими параметрами**
3. Если текущие параметры значительно больше оценочных - СНЭЭ переразмерена
4. Если текущие меньше оценочных - СНЭЭ недостаточна
5. Используйте кнопку **"Установить оценочные параметры"** для применения оптимальных значений

### На SVG визуализации:
- **Сплошные прямоугольники** - текущие параметры
- **Пунктирные линии** - оценочные параметры
- Сравнивайте визуально высоту и ширину прямоугольников с линиями

## 🐛 Устранение неполадок

### Backend не запускается
```bash
cd web/backend
pip install -r requirements.txt
python main.py
```

### Frontend не видит данные
1. Проверьте что backend запущен: http://localhost:8002/api/v1/health
2. Проверьте консоль браузера (F12) на ошибки
3. Проверьте Network tab в DevTools

### Алгоритм возвращает ошибку
- Проверьте входные данные (24 значения)
- Проверьте что КПД в диапазоне 0-1
- Проверьте логи backend в консоли
