Ниже привожу план работ. Помере разработки будут добавляться пункты плана и соответствующие им промпты. Также в качестве контекста проекта необходимо использовать файл \web\Project_context_QP.txt.

План работ добавления второго варианта расчета в проект.
1. Раздвоим текущий функционал, на два одинаковых варианта. 
2. Переделываем второй вариант на расчет по алгоритмам квадратичной оптимизации.
2.1. Меняем функционал определения оптимальных параметров СНЭЭ.

Задаваемые промпты по пункту 1 плана (выполнен, приводится в качестве контекста):
Текущая разработка будет расширять реализованный функционал расчета диспетчерского графика СНЭЭ. Для начала раздвоим текущий функционал, что бы один вариант оставить без изменений, а второй вариант будем дорабатывать. Необходимо сделать переключатель для перехода от одно варианта (реализованного, текущего с использованием алгоритма water-filling) ко второму варианту, который будем дорабатывать и который будет использовать алгоритм квадратичной оптимизации, и обратно с расположением переключателя в секции Hero (секция общая для двух вариантов). Варианты полностью независимы и не пересекаются. Поэтому раздвоеный второй функционал необходимо переименовать добавив ко всем функциям, переменным, если требуется, приставку “_qp”. Далее я буду дорабатывать второй функционал, заменяя методы расчета и т.д. Это будет задано в другом промпте. В этом прмпте алгоритмы расчетов менять на надо, нужно просто сделать компию. Первый вариант необходимо оставить максимально без изменений. Секция Hero и Footer являются общими для двух вариантов. Другие секции и связанные с ними функции  должны быть независимыми для вариантов, их общая структура будет схожа у вариантов, Необходимо проанализировать проект с точки зрения, что раздваивать, но следующие секции необходимо точно раздвоить, добавив к секциям, переменным, функциям во втором варианте приставку “_qp”: Исходные данные (DataInputSection, DataInputSection_qp), Визуализация исходных данных (DataVisualizationSection, DataVisualizationSection_qp), Результаты расчета (ChartsSection, ChartsSection_qp), Схема системы СНЭЭ (SchematicSection, SchematicSection_qp). Схожие секции, переменные и т.д. для второго варианта называй аналогично первому варианту, добавляя приставку _qp.
