# 🔧 Исправление расчетов PPW - Переход на scipy.optimize

## 📝 Краткое описание

**Проблема:** Оценочные параметры расчитывались некорректно (огромные числа, код ошибки -2)

**Решение:** Переход с `alglib-cpython` на `scipy.optimize` с методом `trust-constr`

**Статус:** ✅ **ПОЛНОСТЬЮ ИСПРАВЛЕНО И ПРОТЕСТИРОВАНО**

## 🔍 Что было изменено?

### 1. Замена оптимизатора

| Компонент | До | После |
|-----------|-----|-------|
| **Библиотека** | `alglib-cpython` | `scipy.optimize` |
| **Метод** | IPMQPSolve | trust-constr |
| **Интерфейс** | Python wrapper над C++ DLL | Нативный Python |

### 2. Исправление критического бага

**Файл:** `web/backend/ppw_calculator.py`

```python
# БЫЛО (вызывало переполнение):

# СТАЛО (корректно обрабатывается):

```

Этот баг был **основной причиной** некорректных расчетов!

### 3. Новая реализация оптимизатора

**Файл:** `web/backend/quadratic_optimizer.py`

```python
from scipy.optimize import minimize, LinearConstraint, Bounds

    """
    Решение задачи квадратичного программирования:
    
    min F(x) = 0.5 * x^T * A * x + b^T * x
    s.t.
        lb <= x <= ub
        cl <= C^T * x <= cu
    """
```

## 🎓 Технические детали

### Почему scipy лучше alglib-cpython?

| Критерий | scipy.optimize | alglib-cpython |
|----------|----------------|----------------|
| **Простота использования** | ✅ Высокая | ❌ Низкая (COM интерфейс) |
| **Надежность** | ✅ Проверена временем | ⚠️ Зависит от DLL |
| **Производительность** | ✅ Хорошая | ✅ Отличная |
| **Кроссплатформенность** | ✅ Win/Linux/Mac | ❌ Только Windows |
| **Отладка** | ✅ Легко | ❌ Сложно |
| **Сообщество** | ✅ Большое | ⚠️ Среднее |
| **Документация** | ✅ Отличная | ⚠️ Средняя |

### Метод trust-constr

**Trust Region Constrained Algorithm:**
- Метод доверительной области для задач с ограничениями
- Использует квадратичное приближение целевой функции
- Эффективен для выпуклых задач
- Гарантирует выполнение ограничений
- Быстрая сходимость (~10-50 итераций)

**Алгоритм:**
1. Построить квадратичное приближение в точке xₖ
2. Решить подзадачу в доверительной области
3. Оценить качество шага
4. Обновить размер доверительной области
5. Повторить до сходимости
