## Первый запуск

### Шаг 1: Откройте приложение

Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```
или адрес вашего сервера, если приложение развернуто в сети.

### Шаг 2: Ознакомьтесь с интерфейсом

На главном экране вы увидите:
- **Hero секцию** с описанием возможностей
- **Секцию загрузки данных** (прокрутите вниз)
- Кнопку "Рассчитать график"

## Загрузка данных

Существует **3 способа** загрузить данные:

### Способ 1: Профиль по умолчанию (самый быстрый)

1. Прокрутите до секции "Исходные данные"
2. Нажмите кнопку **"Профиль по умолчанию"**
3. Данные будут загружены автоматически

✅ **Когда использовать**: для первого знакомства с системой или демонстрации

### Способ 2: Загрузка Excel файла

1. Подготовьте Excel файл с 24 значениями баланса мощности
   - Файл должен содержать одну строку или столбец с 24 числами
   - Положительные значения = избыток энергии
   - Отрицательные значения = дефицит энергии

2. **Drag & Drop**: Перетащите файл в зону загрузки
   
   **ИЛИ**
   
   Кликните на зону загрузки и выберите файл через диалог

3. Дождитесь сообщения "Файл успешно загружен!"

✅ **Когда использовать**: для работы с реальными данными из внешних источников

### Способ 3: Ручной ввод

1. Загрузите профиль по умолчанию
2. Прокрутите до секции "Визуализация исходных данных"
3. В разделе "Редактирование значений" измените нужные часы
4. Значения обновятся автоматически

✅ **Когда использовать**: для точной настройки отдельных значений

## Настройка параметров

В секции "Исходные данные" справа находятся параметры СНЭЭ:

### 1. Мощность инвертора (МВт)

**Что это**: Максимальная мощность заряда/разряда батареи

**Пример значений**:
- 100 МВт - малая система
- 500 МВт - средняя система (по умолчанию)
- 1000+ МВт - крупная система

**Как выбрать**: Зависит от пиковых нагрузок в вашей системе

### 2. Емкость батареи (МВтч)

**Что это**: Объем энергии, которую может хранить батарея

**Пример значений**:
- 500 МВтч - малая емкость
- 2000 МВтч - средняя емкость (по умолчанию)
- 5000+ МВтч - большая емкость

**Как выбрать**: Обычно 2-4 часа работы на максимальной мощности

**Пример**: При мощности 500 МВт и 4 часах → 2000 МВтч

### 3. КПД цикла

**Что это**: Эффективность преобразования энергии при заряде-разряде

**Диапазон**: от 0.01 до 1.00

**Типичные значения**:
- 0.80 (80%) - свинцово-кислотные батареи
- 0.90 (90%) - литий-ионные батареи
- 0.95 (95%) - современные Li-Ion (по умолчанию)
- 0.98 (98%) - суперконденсаторы

**Важно**: Значение 0.95 означает, что при полном цикле заряд-разряд вы получите 95% от вложенной энергии, 5% уйдет на потери.

## Выполнение расчета

### Шаг 1: Проверьте данные

Убедитесь, что:
- ✅ Профиль загружен (видно "Профиль загружен: 24 значений")
- ✅ Параметры заполнены корректно
- ✅ КПД в диапазоне 0-1

### Шаг 2: Нажмите "Рассчитать график"

Кнопка находится в центре секции "Исходные данные"

### Шаг 3: Дождитесь результата

- Появится индикатор "Расчет..."
- Через 1-2 секунды страница прокрутится к результатам

### Возможные ошибки

❌ **"Необходимо загрузить корректный профиль"**
- Решение: Загрузите данные (см. раздел "Загрузка данных")

❌ **"Мощность и емкость должны быть положительными"**
- Решение: Проверьте, что все параметры > 0

❌ **"КПД должен быть в диапазоне (0, 1]"**
- Решение: Введите значение от 0.01 до 1.00

## Анализ результатов

После успешного расчета появятся 2 новые секции:

### Секция "Результаты расчета"

#### 1. Ключевые показатели

Четыре карточки с основными метриками:

**Покрытие дефицита**
- Показывает, какой процент дефицита энергии покрыла СНЭЭ
- Пример: 70% означает, что 70% дефицита было компенсировано

**Использование избытка**
- Показывает, какой процент избытка был запасен в батарее
- Пример: 24% означает, что 24% избытка было сохранено

**Суммарный заряд**
- Общая энергия, запасенная за сутки (МВтч)
- + максимальная мощность заряда (МВт)

**Суммарный разряд**
- Общая энергия, выданная за сутки (МВтч)
- + максимальная мощность разряда (МВт)

#### 2. Диспетчерский график

**Как читать график**:

🔴 **Красная область** - исходный баланс
- Выше нуля = избыток энергии
- Ниже нуля = дефицит энергии

🔵 **Синие столбцы** - заряд СНЭЭ
- Потребление энергии из сети для зарядки батареи

🟢 **Зеленые столбцы** - разряд СНЭЭ
- Выдача энергии в сеть из батареи

⚫ **Черная линия** - результирующий баланс
- Итоговый баланс сети с учетом работы СНЭЭ
- Чем ближе к нулю, тем лучше баланс

#### 3. График SOC (State of Charge)

**Что показывает**: Уровень заряда батареи по часам

**Как анализировать**:
- График должен быть плавным (без резких скачков)
- Не должен превышать макс. емкость (красная линия)
- Не должен опускаться ниже нуля
- Желательно к концу суток вернуться к начальному уровню

### Секция "Схема системы СНЭЭ"

#### Интерактивная визуализация

**Слайдер выбора часа**:
- Перемещайте ползунок для выбора часа (1-24)
- Схема обновляется в реальном времени

**Элементы схемы**:

🔋 **Батарея** (слева)
- Зеленый контейнер с индикатором заряда
- Показывает текущий SOC в МВтч и %

⚡ **Инвертор** (центр)
- Синий блок преобразования энергии
- Показывает номинальную мощность

🔌 **Сеть** (справа)
- Оранжевый круг
- Показывает текущий баланс сети

**Анимированные потоки**:
- 🟢 **Зеленые стрелки** → Разряд (батарея → сеть)
- 🔴 **Красные стрелки** → Заряд (сеть → батарея)
- ⚪ **Нет стрелок** → Простой

**Информационная панель**:
- Режим работы (ЗАРЯД/РАЗРЯД/ПРОСТОЙ)
- Мощность СНЭЭ
- Заряд батареи
- Баланс сети

## Частые вопросы

### Общие вопросы

**Q: Что означают положительные и отрицательные значения в профиле?**
A: Положительные = избыток энергии в системе, отрицательные = дефицит (нехватка)

**Q: Почему покрытие дефицита не 100%?**
A: Это зависит от параметров СНЭЭ. Увеличьте мощность и/или емкость для лучшего покрытия.

**Q: Можно ли изменить данные после расчета?**
A: Да, вернитесь к секции "Визуализация исходных данных" и измените значения, затем пересчитайте.

### Технические вопросы

**Q: Какой браузер использовать?**
A: Рекомендуется Chrome, Firefox, Safari или Edge (последние версии). IE 11 не поддерживается.

**Q: Приложение медленно работает**
A: 
- Закройте другие вкладки браузера
- Проверьте скорость интернета (для облачной версии)
- Попробуйте другой браузер

**Q: Не загружается Excel файл**
A: Проверьте, что:
- Файл в формате .xlsx или .xls
- Файл содержит ровно 24 числовых значения
- Файл не поврежден
- Размер файла < 10 МБ

**Q: Ошибка "Failed to fetch"**
A: Backend не запущен или недоступен. Проверьте, что сервер работает.

### Вопросы по расчетам

**Q: Что такое алгоритм water-filling?**
A: Это метод оптимального распределения энергии, который заполняет "емкость" как вода заполняет сосуд - максимально эффективно.

**Q: Почему график SOC не начинается с нуля?**
A: Алгоритм оптимизирует использование всей доступной емкости. Начальное состояние рассчитывается автоматически.

**Q: Как улучшить эффективность СНЭЭ?**
A:
1. Увеличьте мощность инвертора для покрытия пиков
2. Увеличьте емкость батареи для запаса большей энергии
3. Используйте батареи с высоким КПД (>0.90)
