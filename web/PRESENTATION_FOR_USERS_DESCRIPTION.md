# Презентация сайта СНЭЭ Graf для обычных пользователей

## 1. Что это за сайт
СНЭЭ Graf - это веб-сервис, который помогает подобрать параметры системы накопления электрической энергии (СНЭЭ) и построить понятный диспетчерский график работы накопителя на сутки.

Сайт отвечает на практический вопрос:
- какую мощность и емкость накопителя выбрать;
- как будет работать накопитель по часам;
- насколько уменьшится дефицит и насколько эффективно будет использован избыток энергии.

## 2. Какие исходные данные загружаются
Пользователь работает с **суточным профилем баланса мощности** (24 часа):
- можно загрузить Excel-файл (`.xlsx`/`.xls`);
- можно взять профиль по умолчанию;
- можно вручную отредактировать каждое из 24 значений (в том числе вставить диапазон из Excel).

Дополнительно задаются параметры СНЭЭ:
- входная мощность (заряд), МВт;
- выходная мощность (разряд), МВт;
- емкость батареи, МВтч;
- КПД цикла (0..1).

## 3. Что рассчитывается системой
После запуска расчета формируются:
- **диспетчерский график работы СНЭЭ** по часам (заряд/разряд);
- **результирующий баланс мощности** после работы СНЭЭ;
- **SOC-график** (уровень энергии в батарее в каждый час);
- ключевые KPI: покрытие дефицита, использование избытка, суммарный заряд/разряд, пиковые мощности.

## 4. Что можно интерактивно менять
Пользователь может менять данные тремя способами:
- редактировать точки графика баланса (drag-and-drop);
- сдвигать весь профиль целиком вверх/вниз (смещение);
- менять параметры СНЭЭ в полях ввода и в интерактивной SVG-визуализации батареи (перетаскивание маркеров мощности и емкости).

После изменений пересчет выполняется автоматически или по кнопке, и графики обновляются сразу.

## 5. Как определяются оптимальные параметры СНЭЭ
Для пользовательского сценария в системе используется QP-вариант расчета:
- сначала вычисляются **оценочные параметры**: входная мощность, выходная мощность, емкость, а также остаточный дефицит;
- затем эти параметры можно одной кнопкой применить как рабочие;
- после этого строится полноценный диспетчерский график.

Внутри решается оптимизационная задача:
- учитывается 24-часовой профиль;
- соблюдаются ограничения по КПД, мощности заряда/разряда и емкости;
- минимизируется дефицит и одновременно ограничиваются требуемые номиналы мощности/емкости.

Важно для интерпретации QP-режима:
- положительное значение профиля = дефицит;
- отрицательное значение профиля = избыток.

## 6. Как строится график
Логика построения:
1. На вход берется профиль 24 часов и параметры СНЭЭ.
2. Оптимизационный модуль рассчитывает почасовой режим заряда/разряда.
3. Для каждого часа формируется новый баланс:
   - исходный баланс;
   - вклад СНЭЭ;
   - результирующий баланс.
4. Отдельно строится SOC-график, чтобы показать, как меняется запас энергии в батарее.

Визуально пользователь видит:
- где СНЭЭ сглаживает пики дефицита;
- где используется избыток энергии;
- как выбранные параметры влияют на итоговый результат.

## 7. Что получает пользователь в итоге
Сервис помогает перейти от сырых данных к решению:
- понятные рекомендуемые параметры СНЭЭ;
- прозрачная визуализация работы накопителя;
- количественные показатели эффективности;
- экспорт результатов в Excel для отчетности и обсуждения.

## 8. Рекомендуемый сценарий демонстрации
1. Открыть профиль по умолчанию (или загрузить Excel).
2. Показать редактирование пары точек графика.
3. Нажать "Рассчитать оценочные параметры".
4. Применить оценочные параметры.
5. Нажать "Рассчитать диспетчерский график".
6. Разобрать 2-3 KPI: покрытие дефицита, использование избытка, SOC.
7. Выгрузить результат в Excel.
