# СНЭЭ Graf - Вариант PPW (Квадратичная оптимизация)

## Обзор

Второй вариант системы визуализации СНЭЭ с использованием квадратичной оптимизации (Interior Point Method) для расчета оптимальных параметров и графиков нагрузки.

## Основные отличия от первого варианта

### Алгоритм расчета
- **Вариант 1**: Water-filling алгоритм (эвристический подход)
- **Вариант PPW**: Квадратичная оптимизация с IPM solver (точное решение)

### Параметры СНЭЭ
**Вариант 1** использует 3 основных параметра:
- Мощность инвертора (rated_power_mw)
- Емкость батареи (rated_capacity_mwh)
- КПД цикла (efficiency)

**Вариант PPW** использует 10 параметров:
1. Номинальная активная входная мощность (rated_power_in_mw)
2. Номинальная активная выходная мощность (rated_power_out_mw)
3. Номинальная энергоемкость (rated_capacity_mwh)
4. Номинальное время разряда (nominal_discharge_time_h)
5. Коэффициент использования емкости (capacity_utilization_percent)
6. Энергия в рабочем диапазоне (working_range_energy_mwh)
7. Фактическое время разряда (actual_discharge_time_h)
8. Энергоэффективность (КПД) (efficiency)
9. Энергия затраченная на заряд (charge_energy_mwh)
10. Фактическое время заряда (actual_charge_time_h)

### Входные данные
- **Вариант 1**: Профиль баланса мощности (положительные - избыток, отрицательные - дефицит)
- **Вариант PPW**: Баланс мощности энергосистемы (положительные - не покрываемое потребление, отрицательные - избыток генерации)

## Архитектура

### Backend (Python)

#### Модули
1. **quadratic_optimizer.py** - Обертка над alglib-cpython IPM solver
   - Функция `solve_qp_problem()` - решение задачи квадратичного программирования
   - Обработка кодов завершения оптимизации

2. **ppw_calculator.py** - Основные алгоритмы PPW варианта
   - Класс `PPWCalculator`
   - `calculate_optimal_load()` - расчет графика при заданных параметрах
   - `calculate_optimized_parameters()` - расчет оптимальных параметров СНЭЭ

3. **main.py** - API эндпоинты
   - `POST /api/v1/ppw/calculate-load` - расчет графика
   - `POST /api/v1/ppw/calculate-optimal-parameters` - расчет оптимальных параметров

#### Зависимости
- alglib-cpython (версия 4.06.0) - библиотека численной оптимизации
- numpy - математические операции
- fastapi - веб-фреймворк

### Frontend (React)

#### Компоненты
1. **Hero.jsx** - Общая секция с табами переключения вариантов
2. **DataInputSection_ppw.jsx** - Ввод данных и параметров
   - 10 полей параметров с автоматическим пересчетом
   - Загрузка профиля из Excel
   - Ручное редактирование 24 значений
3. **DataVisualizationSection_ppw.jsx** - Визуализация исходных данных
   - График баланса мощности
   - Статистика по профилю
   - Кнопка расчета
4. **ChartsSection_ppw.jsx** - Результаты расчета
   - Ключевые показатели
   - Основной график (исходный, нагрузка СНЭЭ, результирующий)
   - График SOC (состояние заряда)
5. **SchematicSection_ppw.jsx** - Схема потоков энергии
   - Визуализация энергосистема ↔ СНЭЭ
   - Показатели мощности и емкости

## Математическая модель

### Задача оптимизации

Минимизировать: `F(x) = 0.5*x'*A*x + b'*x`

При ограничениях:
- `lb <= x <= ub` (box constraints)
- `cl <= C'*x <= cu` (linear constraints)

### Переменные для calculate_optimal_load
- n = 98 (24*4 + 2)
- k = 96 (24*4)
- Переменные: dL[0..23], CC[24..47], CD[48..71], D[72..95], Dmax[96], Rmax[97]

### Переменные для calculate_optimized_parameters
- n = 76 (24*3 + 4)
- k = 120 (24*5)
- Переменные: dL[0..23], CC[24..47], CD[48..71], Dmax[72], Nin[73], Nout[74], C[75]

## Коды завершения оптимизации

- **2, 4**: Успешное завершение (рекомендуемые)
- **1, 5, 7, 8**: Успешное завершение с альтернативными критериями
- **-2, -3, -4, -5, -9**: Ошибки оптимизации

## Использование

1. Откройте веб-интерфейс
2. Выберите "Вариант 2 (PPW)" в Hero секции
3. Загрузите профиль баланса мощности или используйте данные по умолчанию
4. Настройте параметры СНЭЭ (или оставьте значения по умолчанию)
5. Нажмите "Рассчитать график"
6. Изучите результаты на графиках и схеме

## Приоритеты пересчета параметров

1. **Мощность** (первый приоритет) - изменяется пользователем редко
   - Номинальная входная мощность
   - Номинальная выходная мощность

2. **Энергия** (второй приоритет)
   - Номинальная энергоемкость
   - Энергия в рабочем диапазоне
   - Коэффициент использования емкости

3. **Время и КПД** (третий приоритет) - рассчитываются автоматически
   - Номинальное время разряда
   - Фактическое время разряда
   - Фактическое время заряда
   - КПД
