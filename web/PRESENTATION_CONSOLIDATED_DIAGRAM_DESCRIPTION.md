# Сводная презентация-диаграмма

Объединение исследований из **PRESENTATION_FOR_USERS_DESCRIPTION.md** и **PRESENTATION_OPTIMIZATION_SIMPLE_DESCRIPTION.md** в одну схематичную диаграмму (1 слайд).

## Единственный слайд: полная схема

### Верх — лендинг (Hero)
- **СНЭЭ Graf** — заголовок
- Подзаголовок: «Визуализация диспетчерского графика • Оптимизация СНЭЭ • Интерактивные графики • SVG»
- Строка: «Система накопления электрической энергии | Линейная оптимизация (LP, HiGHS)»

Признаки с лендинга: Оптимизация СНЭЭ, Реальное время, Интерактивные графики, SVG.

### Поток данных (слева направо)

1. **Ввод данных** — профиль 24 ч (Excel / по умолчанию), Nin, Nout, C, КПД η, редактирование графика, смещение
2. **Шаг 1: LP-оптимизация параметров** — linprog → Nin, Nout, C, Dmax; минимизация дефицита, учёт η (CC/η в ограничениях)
3. **Шаг 2: LP-график** — заданные Nin, Nout, C → заряд/разряд по часам, SOC, результирующий баланс
4. **Результат** — диспетчерский график, SOC, KPI, покрытие дефицита, использование избытка, экспорт в Excel

### Справа — интерактивность
- Перетаскивание точек графика
- Смещение профиля
- SVG-батарея (маркеры мощности и ёмкости)

### Низ — ключевые факты
- LP (не QP): scipy.optimize.linprog, HiGHS
- Два шага: параметры → график
- η в ограничениях: CC/η
- Допущения: 24 ч, шаг 1 ч, без деградации, замкнутый цикл
- Ровные участки и пики — следствие оптимума

## Дополнительно (для докладчика): детали LP

### Задача 1 (100 переменных)
- Переменные: L[i], CC[i], CD[i], D[i], Dmax, Nin, Nout, C
- Целевая функция: min Dmax·w1 + ΣD·w2 + Nin·w3 + Nout·w3 + C·w4
- rL: L[i] − L[i−1] − CC[i] + CD[i] = 0
- rD: CC[i]/η − CD[i] − D[i] ≤ −Load[i]
- η — КПД в ограничениях

### Задача 2 (98 переменных)
- Nin, Nout, C заданы; считаются L, CC, CD, D, Dmax, Rmax
- Те же ограничения rL, rD + rRmax
- Результат: EESSLoad[i] = CD[i] − CC[i]/η

### Библиотеки
- NumPy — матрицы и векторы
- SciPy linprog — интерфейс
- HiGHS — симплекс / внутренняя точка

### Полярность и поведение
- Load > 0 = дефицит; Load < 0 = избыток
- Заряд при избытке, разряд при дефиците
- Площадки и пики — следствие ограничений и целевой функции
