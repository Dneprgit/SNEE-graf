# Изменения в масштабировании оси Y графика "Диспетчерский график работы СНЭЭ"

## Дата изменения
07.12.2025

## Описание изменения

Реализовано автоматическое масштабирование оси Y для графика "Диспетчерский график работы СНЭЭ" в веб-версии приложения.

## Логика работы

### 1. Вычисление максимального значения
```javascript
const maxAbsValue = Math.max(...loadProfile.map(v => Math.abs(v)));
```
- Находится максимальное значение **по модулю** из всего суточного профиля баланса мощности
- Учитываются как положительные (избытки), так и отрицательные (дефициты) значения

### 2. Округление до кратного 100 МВт
```javascript
const yAxisMax = Math.ceil(maxAbsValue / 100) * 100;
```
- Максимальное значение округляется **вверх** до ближайшего числа, кратного 100
- Примеры:
  - 450 МВт → 500 МВт
  - 501 МВт → 600 МВт
  - 1050 МВт → 1100 МВт

### 3. Симметричный диапазон
```javascript
const yAxisDomain = [-yAxisMax, yAxisMax];
```
- Используется симметричный диапазон [-max, +max]
- Обеспечивает удобное визуальное представление с нулевой линией посередине

### 4. Автоматическое обновление
- Значения пересчитываются при каждом изменении `loadProfile`:
  - При загрузке нового профиля из Excel
  - При изменении любого значения в таблице
  - При выборе профиля по умолчанию
