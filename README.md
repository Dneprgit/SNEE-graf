# СНЭЭ - Визуализация диспетчерского графика

Программа для визуализации и анализа работы Системы Накопления Электрической Энергии (СНЭЭ) мощностью от 100 МВт и выше.

## Описание

СНЭЭ — это электроустановка, подключённая к электрической сети, которая извлекает, хранит и отдаёт обратно в сеть электрическую энергию. Ключевая задача — снижение зависимости от дорогой пиковой генерации и стабилизация затрат для потребителей.

Программа позволяет:
- Анализировать возможность использования СНЭЭ для прохождения максимума нагрузки в дефицитных районах
- Визуализировать суточный баланс мощности и диспетчерский график работы СНЭЭ
- Редактировать исходные данные вручную или импортировать из Excel
- Экспортировать результаты в Excel и HTML

## Основные возможности

### Функциональность
- ✅ Расчет оптимального диспетчерского графика работы СНЭЭ (алгоритм water-filling)
- ✅ Интерактивная визуализация с помощью Plotly
- ✅ Редактируемая таблица суточного баланса мощности (24 часа)
- ✅ Импорт данных из Excel
- ✅ Экспорт результатов в Excel и HTML
- ✅ Настраиваемые параметры: мощность инвертора, емкость батареи, КПД
- ✅ Автоматический пересчет при изменении параметров
- ✅ Сводная информация о покрытии дефицитов и использовании избытков

### Визуализация
- Суточный график баланса мощности (избыток +, дефицит -)
- График работы СНЭЭ (заряд/разряд)
- Результирующий баланс с учетом работы СНЭЭ
- Состояние заряда батареи (SOC) в течение суток

## Установка и запуск

### Требования
- Python 3.8 или выше
- Windows 10/11

### Установка зависимостей

1. Создайте виртуальное окружение:
```bash
python -m venv venv
```

2. Активируйте виртуальное окружение:
```bash
# Windows
venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

### Настройка

1. Скопируйте файл `env.example` в `.env`:
```bash
copy env.example .env
```

2. При необходимости отредактируйте значения в `.env`:
- `DEFAULT_INVERTER_POWER` - мощность инвертора по умолчанию (МВт)
- `DEFAULT_BATTERY_CAPACITY` - емкость батареи по умолчанию (МВтч)
- `DEFAULT_EFFICIENCY` - КПД трансформации по умолчанию
- `WINDOW_WIDTH` и `WINDOW_HEIGHT` - размеры окна приложения

### Запуск программы

```bash
python main.py
```

## Компиляция в EXE

Для создания standalone исполняемого файла:

```bash
pyinstaller --name="SNEE_Graf" ^
            --windowed ^
            --onefile ^
            --icon=icon.ico ^
            --add-data="env.example;." ^
            main.py
```

Исполняемый файл будет создан в папке `dist/`.

## Использование

### Интерфейс программы

1. **Параметры СНЭЭ** (верхняя панель):
   - Мощность инвертора, МВт
   - Емкость батареи, МВтч
   - КПД трансформации (0-1)

2. **Исходные данные**:
   - Таблица с 24 часовыми значениями баланса мощности
   - Редактируемые ячейки
   - Кнопки "Импорт из Excel" и "Сбросить к исходным"

3. **Рассчитанные данные**:
   - График СНЭЭ (+ разряд, - заряд)
   - Результирующий баланс
   - Состояние заряда батареи (SOC)

4. **Сводная информация**:
   - Энергетические показатели
   - Покрытие дефицитов
   - Использование избытков

5. **Интерактивная диаграмма**:
   - Визуализация баланса и работы СНЭЭ
   - График состояния заряда батареи
   - Масштабирование, панорамирование
   - Экспорт в PNG через меню Plotly

### Импорт данных из Excel

Файл Excel должен содержать строку или столбец с 24 числовыми значениями (баланс мощности по часам). Программа автоматически найдет и импортирует данные.

Пример структуры Excel файла:
```
Час    1      2      3    ...   24
МВт    1320   1515   1623 ...   963
```

### Экспорт результатов

**В Excel:**
- Лист "Данные": почасовые значения баланса, графика СНЭЭ, результирующего баланса
- Лист "Сводка": ключевые показатели работы системы

**В HTML:**
- Интерактивный график, который можно открыть в браузере
- Полная функциональность Plotly (масштабирование, панорамирование, экспорт изображений)

## Алгоритм расчета

Программа использует алгоритм **water-filling** для оптимального распределения заряда/разряда СНЭЭ:

1. Определение почасовых лимитов заряда и разряда с учетом:
   - Номинальной мощности инвертора
   - Профиля баланса (избыток/дефицит)
   - КПД полуцикла

2. Расчет используемой энергии (минимум из: возможного заряда, возможного разряда, емкости батареи)

3. Определение оптимальных уровней заряда и разряда методом water-filling

4. Формирование почасового графика мощности на шинах с учетом потерь

Алгоритм портирован с VBA и обеспечивает максимальное использование СНЭЭ для:
- Покрытия дефицитов мощности в часы пиковой нагрузки
- Утилизации избытков в часы минимальной нагрузки
