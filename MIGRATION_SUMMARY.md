# Итоговый отчет: Миграция QP алгоритма

## 📋 Краткое описание

Успешно выполнена миграция алгоритма квадратичной оптимизации из VB/Excel (Module1.bas, функция `GetEESSOptimalLoad`) в Python с использованием библиотеки scipy. Алгоритм интегрирован в веб-приложение СНЭЭ Graf для второго варианта расчетов (QP).

## ✅ Выполненные задачи

### 1. Backend (Python)

#### ✅ Создана функция `_solve_qp_optimization` 
**Файл**: `web/backend/energy_storage_calculator.py`

Реализует решение задачи квадратичной оптимизации:
- Минимизация: F(x) = 0.5 * x' * A * x + b' * x
- Ограничения: lb ≤ x ≤ ub и cl ≤ C' * x ≤ cu
- Переменные: 98 (dL[24] + CC[24] + CD[24] + D[24] + Dmax + Rmax)
- Ограничения: 96 (rL[24] + rD[24] + rDmin[24] + rDmax[24])

**Ключевые особенности:**
- Использование scipy.optimize.minimize с методом 'trust-constr'
- Точная реализация матриц A, b, C согласно VB коду
- Корректная обработка циклических индексов (i=0 → i-1=23)
- Учет полярности баланса для QP (+ дефицит, - избыток)

#### ✅ Переписан метод `calculate_dispatch_schedule_qp`
**Файл**: `web/backend/energy_storage_calculator.py`

Теперь возвращает словарь с полными результатами QP оптимизации:
- `eess_load`: график нагрузки СНЭЭ (24 часа)
- `soc_energy`: график заряда батареи (24 часа) - dblEENSEnergyAvailable
- `deficit`: дефицит мощности (Dmax)
- `reserve`: резерв мощности (Rmax)

Формула извлечения:
```python
dblEENSLoad[i] = CD[i] - CC[i]/efficiency
```

## 🎯 Критические моменты реализации

### 1. Полярность баланса
**Самое важное отличие!**
- QP: положительное = дефицит, отрицательное = избыток
- Первый вариант: противоположная полярность
- Это учтено в:
  - get_summary_qp (инверсия при расчете deficit/surplus)
  - Пользовательском интерфейсе (пояснения)
  - Документации

### 2. Индексация
- VB использует индексацию с 1
- Python использует индексацию с 0
- Корректная трансформация выполнена во всех местах

### 3. Циклическая связь
- Для i=0, предыдущий элемент i-1 = 23
- Реализовано через: `j = (i - 1) if i > 0 else (im - 1)`

### 4. Извлечение результатов
- VB формула: `dblEENSLoad(i) = x(i + im * 2) - x(i + im) / dblEfficiency`
- Python: `dbl_eens_load[i] = x[i + im * 2] - x[i + im] / self.efficiency`
- Индексы корректно смещены на -1

### 5. SOC из QP
- Используем dblEENSEnergyAvailable напрямую из x[0:24]
- НЕ пересчитываем через calculate_soc
- Это точное значение энергии в батарее из оптимизации
