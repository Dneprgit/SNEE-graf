# Журнал изменений

## Версия 2.0.0 (Декабрь 2025)

### 🎉 Новое - Web версия

**Полнофункциональная современная веб-версия СНЭЭ Graf**

#### Backend (FastAPI)
- ✅ **REST API** с 5 эндпоинтами
  - Health check
  - Получение профиля по умолчанию
  - Расчет диспетчерского графика
  - Загрузка Excel файлов
  - Валидация профиля баланса
- ✅ **Auto-generated документация** (Swagger UI / ReDoc)
- ✅ **CORS поддержка** для работы с фронтендом
- ✅ **Валидация данных** с Pydantic
- ✅ **Обработка ошибок** с понятными сообщениями
- ✅ **Интеграция** с существующими модулями расчета

#### Frontend (React)
- ✅ **Современный UI** с Tailwind CSS
- ✅ **6 секций лендинга**:
  1. Hero - приветственная секция с анимацией
  2. Data Input - загрузка данных и параметров
  3. Data Visualization - визуализация и редактирование профиля
  4. Charts - графики результатов расчета
  5. Schematic - интерактивная SVG схема системы
  6. Footer - футер с контактами
- ✅ **Интерактивные графики** на базе Recharts
- ✅ **SVG визуализация** с анимацией потоков энергии (D3.js + Framer Motion)
- ✅ **Drag & Drop** загрузка Excel файлов
- ✅ **Экспорт результатов** в Excel
- ✅ **Редактирование данных** в реальном времени
- ✅ **Адаптивный дизайн** для всех устройств

#### Технологический стек
- **Backend**: FastAPI, Uvicorn, NumPy, Pandas, Pydantic
- **Frontend**: React 18, Vite, Tailwind CSS, Recharts, D3.js, Framer Motion
- **Tools**: Axios, React Dropzone, XLSX, Lucide React

#### Инфраструктура

## Версия 1.0.1 (Декабрь 2025)

### 🎉 Новое

- **Компиляция в EXE файл** (~220 МБ)
  - Создан файл спецификации SNEE_Graf.spec для PyInstaller
  - Готовый standalone EXE в папке dist/
  - Включены все зависимости (Python, PyQt6, Chromium)
  - Документация по распространению (DISTRIBUTION.md)

- **Документация для GitHub**
  - .github/README.md для отображения на GitHub
  - BRANCHES.md - описание структуры веток
  - DISTRIBUTION.md - инструкции по распространению EXE

### 🐛 Исправления

- **Добавлена зависимость PyQt6-WebEngine** в requirements.txt
  - Исправлена ошибка: `ModuleNotFoundError: No module named 'PyQt6.QtWebEngineWidgets'`
  - Этот модуль необходим для отображения интерактивных графиков Plotly в GUI
  - Обновлен run.bat для автоматической установки

### 📦 Изменения в зависимостях

```diff
  numpy>=1.24.0
  pandas>=2.0.0
  openpyxl>=3.1.0
  plotly>=5.18.0
  PyQt6>=6.6.0
+ PyQt6-WebEngine>=6.6.0
  python-dotenv>=1.0.0
  pyinstaller>=6.0.0
```

### 📝 Примечание

PyQt6-WebEngine - это отдельный пакет от PyQt6, который содержит компоненты Chromium для отображения веб-контента. Он необходим для работы QWebEngineView, используемого для отображения графиков Plotly.

## Формат журнала

Этот проект следует принципам [Semantic Versioning](https://semver.org/):
- **MAJOR** (X.0.0) - несовместимые изменения API
- **MINOR** (0.X.0) - новая функциональность (обратно совместимая)
- **PATCH** (0.0.X) - исправления ошибок

### Типы изменений:
- 🎉 **Новое** - новые функции
- 🐛 **Исправления** - исправление ошибок
- ⚡ **Улучшения** - повышение производительности
- 📝 **Документация** - изменения в документации
- 🔧 **Конфигурация** - изменения в настройках
- ♻️ **Рефакторинг** - изменения кода без изменения функциональности
- ✅ **Тесты** - добавление или изменение тестов
